# Датасет: 4-хоповый граф внутрибанковских переводов (июль 2026)

Граф переводов от 81 клиента, только по исходящим.

| Параметр | Значение |
|---|---|
| Seed | 81 gid |
| Период | 2026-07-01 — 2026-07-31 |
| Глубина обхода | 4 колена |
| Направление | только исходящие |
| Порог по сумме | ≥ 5 000 KZT |
| Охват | только внутрибанковские переводы |

Распределение по коленам: seed — 81, 1-е — 472, 2-е — 462, 3-е — 789, 4-е — 444.
Итого 2 248 узлов, 3 119 рёбер, 4 840 транзакций, оборот 365 890 012 KZT.

## Файлы

**`data/edges.parquet`** — пара плательщик→получатель, агрегированная за период:
`src`, `dst` (int64), `sum_kzt` (float64), `n_tx` (int64), `depth` (int8, 1–4).

**`data/nodes.parquet`** — уникальный клиент: `gid` (int64),
`depth` (минимальное колено, 0 = seed), `is_seed` (bool).

**`data/transactions.parquet`** — отдельная транзакция: `src`, `dst`, `date`, `sum_kzt`.

## Качество и ограничения (объявлены организаторами заранее)

| Особенность | Что это значит |
|---|---|
| Обрыв на 4-м колене: 444 узла с `depth=4` и нулевыми исходящими | наивное `out_deg = 0 ⇒ сток` даёт 444 ложных конечных получателя |
| Видны только исходящие переводы | полный баланс узла посчитать нельзя |
| У seed входящие занижены | отношение «отдал / получил» недостоверно; 354 узла отдают больше, чем получили |
| Порог 5 000 KZT | дробление ниже порога невидимо |
| 19 из 81 seed отсутствуют в рёбрах, ещё 12 только как получатели | 31 seed без исходящих |
| 16 слабосвязных компонент: 1 877 узлов, 270, остальные от 2 до 17 | сеть не монолитна |
| Нет атрибутов клиента | только структура и суммы |
| Нет размеченных ролей | оценка по обоснованности критериев, не по accuracy |

Данные обезличены: `gid` — синтетический идентификатор без привязки к личности.
Предоставлены исключительно для использования в рамках хакатона.
